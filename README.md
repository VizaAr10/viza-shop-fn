# Viza Shop FN - Sitio web

Archivos listos para GitHub Pages.

## Importante

Sube todo lo que está dentro de esta carpeta al repositorio:

- index.html
- styles.css
- script.js
- assets/
- README.md

No subas el ZIP completo.

## Tienda en vivo

La tienda se carga desde Fortnite-API.com y calcula el precio en MXN con la tarifa de $9.50 por cada 100 pavos.

Si no carga en Brave, desactiva Brave Shields para la página o prueba Chrome/Edge.
