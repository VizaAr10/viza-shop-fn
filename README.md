# Viza Shop FN - Sitio web

Versión con tienda de Fortnite en vivo y precios calculados en MXN con base en $9.50 por cada 100 pavos.

## Archivos

- `index.html`: contenido principal.
- `styles.css`: diseño visual.
- `script.js`: tienda en vivo y cálculo automático de precios.
- `assets/logo.png`: logo.

## Actualizar en GitHub Pages

1. Borra los archivos anteriores del repositorio.
2. Sube todo el contenido de esta carpeta, no el ZIP.
3. Haz Commit changes.
4. Espera unos minutos y abre tu página.
