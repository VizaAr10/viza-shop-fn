# Viza Shop FN - Sitio web corregido

Sitio web estático listo para GitHub Pages.

## Cambios de esta versión

- Corrige la carga de la tienda en vivo usando el endpoint actual de Fortnite-API: `/v2/shop`.
- Mantiene el precio base de $9.50 MXN por cada 100 pavos.
- Calcula automáticamente el precio en MXN de cada artículo.
- Conserva botones de WhatsApp, Instagram y Facebook.
- Incluye menú superior: Inicio, Precios, Tienda en vivo, Cómo comprar y Contacto.

## Cómo subirlo

1. Borra del repositorio los archivos anteriores: `index.html`, `styles.css`, `script.js` y la carpeta `assets`.
2. Sube todos los archivos de esta carpeta, no el ZIP completo.
3. Haz commit.
4. Espera de 2 a 5 minutos.
5. Abre: https://vizaar10.github.io/viza-shop-fn/

Nota: La tienda en vivo depende de Fortnite-API.com, una API externa no oficial. Si la API se cae o bloquea peticiones, la sección puede mostrar un aviso temporal.
